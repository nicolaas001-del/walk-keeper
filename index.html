Past walks

Tap "Garmin" on a walk to save it as a file. Then add that file to Garmin Connect (see the help below).
Help: Garmin

Live heart rate: on the watch, start "Broadcast Heart Rate" (on most watches: hold the Menu button, or open the Controls menu). Then push "Connect Garmin heart rate" here. With heart rate, the calories are more correct.

Add a walk to Garmin Connect: push "Garmin" on the walk and save the file to Files. On a computer, go to connect.garmin.com, click the cloud icon (top right) → "Import Data", and pick the file. In Garmin Connect, change the activity type to "Treadmill walking" if you want.
